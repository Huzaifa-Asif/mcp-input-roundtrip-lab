# Contributing

Open an issue before a large protocol or report-contract change. Keep the analyzer dependency-free, deterministic, bounded, offline, and usable without the browser UI.

1. Fork and create a focused branch.
2. Add or update synthetic fixtures and tests.
3. Run `npm run check` on Node 20 or newer.
4. Confirm no launch drafts, covers, secrets, or real transcripts are tracked.
5. Explain specification sources, compatibility impact, and limitations in the pull request.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Contributions are accepted under the MIT license.
