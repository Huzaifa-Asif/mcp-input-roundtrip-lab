# Privacy

The browser build processes transcript text only in the current page. It has no analytics, accounts, cookies, network requests, persistence, or server-side component. The CLI reads the file supplied by the operator and writes its report to standard output.

Transcript content can contain secrets or personal data. Use synthetic or redacted captures where possible and review reports before sharing because evidence can include bounded identifiers and method names. The project does not define retention for files held by the browser, shell, static host, or operator.

Privacy questions can be filed through the repository's support channel without attaching a sensitive transcript.
